# 治理规范

## 项目目标

MathAI 旨在成为**开源、可协作**的 LLM 数学解题框架，涵盖题目、知识、工具与工作流，而非单一闭源产品。

## 决策原则

1. **数学正确性优先** — 知识库与参考解答须经过核对
2. **可复现** — 工具脚本、验证流程应可重复运行
3. **渐进式扩展** — 先保证结构与质量，再扩充题量
4. **LLM 友好** — 文件结构、命名、Skill 格式便于 Agent 检索

## 目录所有权

| 领域 | 主要维护内容 |
|------|--------------|
| 问题库 | 格式规范、难度标准、标签体系 |
| 知识库 | 定理准确性、与题目的交叉引用 |
| 工具 | 依赖管理、向后兼容 |
| Skills | Cursor Skill 格式、工作流一致性 |

## 合并标准

- 至少一名维护者 Review（初期可由 Owner 自审）
- CI/验证通过（若有 `verification`）
- 不破坏现有题目 `id` 与路径（除非有迁移说明）

## 版本策略

- `0.x.y` — 早期快速迭代
- `1.0.0` — 结构稳定、核心工具可用、题目库达一定规模后发布

## 长期方向

- [ ] 对接形式化证明（Lean）
- [ ] 题目批量导入（MATH、GSM8K 格式）
- [ ] 自动化评测流水线
- [ ] 多语言知识库
