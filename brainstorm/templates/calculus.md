# 微积分头脑风暴模板

卡住或不确定方法时，按此模板换角度思考，然后回到 `skills/calculus-solver`。

## 1. 重述

- **求什么**：极限值 / 导数 / 不定积分 / 定积分 / 极值 / 面积？
- **结构特征**：复合？乘积？分式？根式？分段？
- **区间**：无穷？对称？周期？

## 2. 快速分类

| 若看到… | 先试… |
|---------|-------|
| $f(g(x))$ | 链式法则 |
| $u \cdot v$ | 乘积法则或分部积分 |
| $\frac{0}{0}$ | 因式分解 → 洛必达 → 等价无穷小 |
| $e^{(\text{多项式})}$ | 换元 $u=$ 指数上 |
| $\sqrt{a^2-x^2}$ | 三角换元 $x=a\sin\theta$ |
| 对称区间 $[-a,a]$ | 奇偶性 |
| 闭区间最值 | 驻点 + 端点 |
