## 常用武器

| 工具 | 说明 |
|------|------|
| 乘法原理 / 加法原理 | 基础计数 |
| 容斥原理 | "至少"问题 |
| 递推 / DP | 可分解子结构 |
| 双射 | 两集合等势 |
| 鸽巢原理 | 存在性 |
| 不变量 / 单调量 | 博弈、操作问题 |
| 生成函数 | 复杂约束计数 |

## brainstorming 清单

1. **小 $n$**：$n=1,2,3,4$ 手算找规律
2. **补集**："至少一个" → 总数 - "一个都没有"
3. **对称性**：能否除以 2 避免重复计数？
4. **递推关系**：增加一个元素如何变化？
5. **OEIS**：查数列是否已知
