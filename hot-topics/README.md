## 榜单结构

每期包含：

1. **学术热点** — 重要论文、会议（NeurIPS、ICML、IMO 等）
2. **工具与项目** — 新发布的开源项目
3. **竞赛动态** — IMO、Putnam、ICPC 等
4. **社区讨论** — 高票问答、争议话题
5. **本仓库进展** — 新增题目、Skills、工具

## 更新流程

每月初由维护者或社区 PR 更新：

1. 复制上月文件为 `YYYY-MM.md`
2. 填写当月内容
3. 更新本 README 索引表
4. PR 标题：`[hot-topic] YYYY-MM 热点榜单`
