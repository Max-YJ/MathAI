# 解题策略总览

## Polya 四步法

1. **理解题目 (Understand)**：未知量是什么？条件是什么？条件是否充分？
2. **拟定计划 (Plan)**：是否见过类似题？能否化归到已知问题？
3. **执行计划 (Execute)**：逐步推导，检验每一步
4. **回顾 (Review)**：能否换种方法？结果是否合理？

## 常用化归策略

| 策略 | 适用场景 |
|------|----------|
| 换元 | 复杂表达式、三角代换 |
| 特值法 | 选择题、寻找反例 |
| 极端原理 | 存在性证明、最值问题 |
| 归纳法 | 与自然数 $n$ 相关的命题 |
| 反证法 | 唯一性、无理数证明 |
| 构造法 | 存在性证明、不等式取等 |

## 与 LLM 协作建议

1. **先选 Skill**：根据题型选择 `skills/` 下对应工作流
2. **引用知识库**：`@knowledge/...` 注入相关定理
3. **分步验证**：用 `tools/verify.py` 检验数值/符号结果
4. **头脑风暴**：卡住时参考 `brainstorm/` 模板换角度思考
