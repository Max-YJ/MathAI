# 竞赛证明 (Olympiad Proof)

## 何时使用

- 题目要求"证明"、"show that"
- 难度 4–5，标签含 `olympiad`
- 需要严格逻辑链而非数值答案

## 工作流程

### 1. 审题与分类

- 确定题型：不等式 / 数论 / 组合 / 几何 / 代数
- 检索 `knowledge/` 中相关定理（如 AM-GM、模运算）
- 参考 `brainstorm/` 中的策略模板

### 2. 探索（可简短头脑风暴）

列出 2–3 种可能路线，选最有希望的一条：
- 直接证明 vs 反证法 vs 归纳法
- 构造辅助量 / 换元 / 极端原理

### 3. 严格证明

每一步必须是以下之一：
- **公理/定义**的直接应用
- **已知定理**（需注明名称）
- **由前述步骤**的逻辑推导

禁止跳步。关键不等式取等条件需说明。

### 4. 完整性检查

- [ ] 是否覆盖所有情况（$n=1$ 基础步、边界条件）？
- [ ] 是否用到未证明的直觉性断言？
- [ ] 等号/取等条件是否讨论？

## 输出格式

```markdown
## 题型与策略
...

## 关键引理（如有）
**引理 1**：...

## 证明
**证明**：...

## 备注
- 等号条件：...
- 其他解法：...
```

## 常用工具

- 不等式：`knowledge/algebra/am-gm-inequality.md`
- 数论：`knowledge/number-theory/`
- 头脑风暴：`brainstorm/templates/inequality.md`

## 注意

- 证明题通常无自动化验证，但可对特例用 SymPy 数值检验
- 鼓励在证明后给出 $n=2,3$ 等特例验证增强信心
