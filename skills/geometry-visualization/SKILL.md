# 几何可视化 (Geometry Visualization)

## 何时使用

- 涉及图形、角度、面积、体积
- 坐标几何、向量法
- 需要直观理解辅助线或构造

## 工作流程

### 1. 画图

- 用文字 ASCII 图或建议用 matplotlib/TikZ 绘制
- 标注已知量、待求量、辅助线
- 建立坐标系（若用解析法）

### 2. 选择方法

| 类型 | 方法 |
|------|------|
| 纯几何 | 全等、相似、圆性质、面积法 |
| 解析几何 | 坐标、直线/圆方程、距离公式 |
| 向量 | 点积、叉积、重心坐标 |
| 三角 | 正弦余弦定理 |

### 3. 推导

- 几何关系 → 代数关系
- 注意图形一般性与退化情况

### 4. 可视化验证（可选）

```python
import matplotlib.pyplot as plt
import numpy as np
# 绘制图形验证点、线、圆关系
```

## 提示

- 遇到复杂图形时，先考虑**坐标化**降低难度
- 面积法常能避免繁琐的辅助线
