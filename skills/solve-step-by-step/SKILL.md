# 逐步求解 (Solve Step-by-Step)

## 何时使用

- 用户要求"一步步解"、"详细过程"、"推导"
- 难度 1–3 的计算题、求解题
- 需要可审查的中间步骤

## 工作流程

### 1. 理解题目

- 复述已知条件与求解目标
- 识别涉及的知识点（查阅 `knowledge/` 若需要）
- 评估难度，选择合适方法

### 2. 拟定计划

- 列出 2–5 个关键步骤大纲
- 说明选用方法的理由（如：因式分解 vs 求根公式）

### 3. 逐步执行

每一步必须包含：
- **操作**：具体数学变换
- **依据**：引用的定理/公式/法则
- **结果**：该步得到的表达式

格式示例：

```
步骤 1 [因式分解]：
  x² - 5x + 6 = (x-2)(x-3)
  依据：十字相乘法 / 多项式因式分解
```

### 4. 验证

- 对计算题：使用 `python -m tools.verify` 或 `sympy_helpers` 检验
- 回代原题检查
- 检查定义域、边界条件

### 5. 总结

- 给出最终答案（LaTeX 格式）
- 一句话概括解法

## 输出格式

```markdown
## 题目理解
...

## 解题计划
1. ...
2. ...

## 详细解答
### 步骤 1：...
### 步骤 2：...

## 验证
...

## 答案
...
```

## 工具集成

- 符号计算：`from tools.sympy_helpers import solve_equation, differentiate`
- 自动验证：`python -m tools.verify --problem <path>`

## 知识库参考

- 通用策略：`knowledge/problem-solving/strategies.md`
- 按领域查阅 `knowledge/<domain>/`

## 示例

**输入**：求 x² - 5x + 6 = 0 的根

**输出**：分步因式分解 → (x-2)(x-3)=0 → x=2 或 x=3 → 验证通过
