# 外部链接

精选的论文、算法、论坛、开源项目等外部资源，按主题分类维护。

## 分类索引

| 文件 | 内容 |
|------|------|
| [papers.md](papers.md) | 学术论文 — 数学推理、定理证明、LLM 数学能力 |
| [algorithms.md](algorithms.md) | 经典算法与数据结构（数论、组合、数值） |
| [forums.md](forums.md) | 社区论坛 — 问答、讨论、竞赛 |
| [projects.md](projects.md) | 开源项目 — 形式化证明、符号计算、数学 AI |

## 维护原则

- 优先收录**长期稳定**、**高质量**资源
- 每条链接附一句话说明
- 失效链接在 PR 中标记或移除
- 新增链接请注明推荐场景

## 贡献

在对应分类文件中按格式添加：

```markdown
- [名称](URL) — 一句话描述
```

提交 PR 至 `main`，参见 [CONTRIBUTING.md](../maintenance/CONTRIBUTING.md)。
