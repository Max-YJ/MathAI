# 论坛与社区 (Forums)

## 数学问答

- [Math Stack Exchange](https://math.stackexchange.com/) — 各层次数学问答，质量高
- [MathOverflow](https://mathoverflow.net/) — 研究级数学讨论
- [知乎 - 数学话题](https://www.zhihu.com/topic/19551275) — 中文数学讨论

## 竞赛数学

- [Art of Problem Solving (AoPS)](https://artofproblemsolving.com/) — 竞赛数学社区、题库
- [IMO Official](https://www.imo-official.org/) — 国际数学奥林匹克
- [CMO / 中国数学奥林匹克](https://www.cms.org.cn/) — 中国数学会

## AI + 数学

- [Hugging Face - MATH leaderboard](https://huggingface.co/spaces) — 检索数学推理模型排行
- [r/MachineLearning](https://www.reddit.com/r/MachineLearning/) — ML 论文讨论
- [Lean Zulip](https://leanprover.zulipchat.com/) — Lean 形式化数学社区

## 学习交流

- [3Blue1Brown Discord](https://www.3blue1brown.com/) — 可视化数学
- [Brilliant](https://brilliant.org/) — 交互式数学学习
