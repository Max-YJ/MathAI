# 资源收集

教材、课程、数据集等学习资源的 curated 列表。

## 分类

| 文件 | 内容 |
|------|------|
| [books.md](books.md) | 书籍推荐 |
| [courses.md](courses.md) | 在线课程 |
| [datasets.md](datasets.md) | 数学数据集（评测、训练） |

## 与 links/ 的区别

- `links/` — 工具、论文、社区、项目（偏**参考**）
- `resources/` — 系统性**学习路径**与数据资源

## 贡献

按分类添加条目，注明难度级别与适用人群。
